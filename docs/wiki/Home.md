# Halocline

Halocline is a desktop music player for live streaming. Your music files and songs from the cloud
(YouTube Music, for now) share one queue. A built-in OBS overlay shows what's playing, and an HTTP
API lets stream bots queue songs and control playback.

This wiki is the user manual. It covers Halocline **0.2**.

## Getting started

1. [Install Halocline](Installing).
2. Add your music folders, and sign in to YouTube Music if you use it: see [Library](Library) and
   [Cloud music](Cloud-music#signing-in).
3. [Play some music](Playing-music): search, paste a link, or drag songs around the queue.
4. Put the song on stream with an [OBS overlay](OBS-overlays).
